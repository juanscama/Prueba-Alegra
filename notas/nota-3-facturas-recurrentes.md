# Nota de cambios · Facturas recurrentes

**Fecha:** viernes de esta semana · **Equipo:** Ventas · **Planes:** solo **Pro**

Nueva función: facturas que se emiten solas cada cierto tiempo, para clientes con cuotas fijas.

- Se crea en **Ventas > Facturas recurrentes > Nueva recurrente**.
- Se elige el cliente, las líneas (como en una factura normal), la **frecuencia** (mensual, trimestral o
  anual) y la **fecha de la primera emisión**.
- Cada factura se emite sola a las 8:00 de su fecha, con la numeración normal.
- Opción **Enviar por correo al emitir** (desmarcada por defecto).
- Para dejar de emitir, se pulsa **Finalizar**. Una recurrente finalizada no se puede reactivar.

**Todavía no disponible:** pausar una recurrente, ni cambiar el importe de las que ya se emitieron.
